OWNERSHIP & PRIVACY

The owner controls the memory layer
Your own installation

Each person runs a separate, self-hosted instance. EV has one owner per
instance.

Selective model access

Privacy rules restrict which context can reach hosted AI providers.

Portable history

Export and correction paths keep the memory independent of the model
provider.

Local-first storage does not mean fully offline AI. Current reasoning and live speech use hosted services. Security depends on correct setup and needs independent review.
